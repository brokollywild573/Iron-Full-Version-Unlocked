## Overview
<a id="overview"></a>

Iron is a web browser developed by SRWare, based on the popular Google Chrome, designed to enhance user privacy while browsing the internet. With growing concerns over online privacy, Iron addresses these issues by omitting the transmission of personal data that is typically shared by Google Chrome, such as client IDs and error reports. This makes Iron a preferred choice for users who prioritize their online privacy while still enjoying a fast and familiar browsing experience. Compared to typical alternatives, Iron maintains the core functionalities of Chrome while enhancing user privacy.
